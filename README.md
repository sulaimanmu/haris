# Haris | حارس — Sulaiman Almukhaizeem

Website: https://sulaimanmu.github.io/haris/

A founder-led, bilingual SIAP 2026 application and prototype evidence site. The public site now includes the full application, professional CV background, the original CV and six PDFs at the applicant's request. Civil ID, private correspondence, runtime credentials and real customer data are excluded.

## Reading paths

- `index.html`: Sulaiman's background, a simple explanation and three recorded situations.
- `application.html`: all 17 official fields and CV background in English/Arabic.
- `library.html`: the complete application and supporting reading room.
- `deck.html`: the actual nine slides with readable original text.
- `notes/`: ten standalone HTML documents covering the pitch/Q&A, problem, business case, architecture, threat model, evaluation, sources, controls and alternatives.
- `evidence.html`: all 48 recorded cases, actual application captures, raw measurements and the local source download.

The core pages work as static HTML without JavaScript. JavaScript switches languages and selects recorded scenarios; no model runs in the public browser. The technical documents retain their English originals. The complete application and CV summary are bilingual.

## Hosting and maintenance

GitHub Pages publishes the `main` branch root. No framework, build service, account or paid API is required to view the site. `.nojekyll` preserves plain static assets; `.gitattributes` preserves byte-exact downloads. The source archive is the runnable local Python application, separate from this presentation site.

The website presents a synthetic prototype. No CBK approval, funding, licensing, sandbox admission, bank deployment or commercial demand is claimed.
