# Haris | حارس

Evidence website for a locally deployable AI security gateway prototype.

**Website:** https://sulaimanmu.github.io/haris/

The English/Arabic explorer presents recorded results from 48 fixed cases, including known failures, actual application screenshots, architecture and downloadable technical evidence. It does not execute a model in the browser. Download `downloads/Haris-Local-Demo.zip` to run the full prototype locally.

All demonstration data is synthetic. No CBK approval, funding, licensing, sandbox admission or bank adoption is claimed.

## Hosting

This repository contains plain HTML, CSS, JavaScript and static evidence. GitHub Pages publishes the `main` branch root; `.nojekyll` preserves the static files without a build system. No account, analytics, paid API or hosted model is required to view the website.

The personal application and CV are supplied privately by email and are excluded from this repository.
